Build the complete frontend of a production-style farmer-focused web application called **AI Khet Saathi**.

IMPORTANT:

* Build ONLY the frontend in this phase.
* Use React.
* Do NOT create Django/backend code.
* Do NOT depend on a real API.
* Use realistic static/mock JSON data for all frontend testing.
* The frontend must be fully functional and interactive using mock data.
* Later, this frontend will be connected to a Django REST Framework backend.
* Keep the frontend architecture API-ready so replacing mock services with real APIs is easy.
* Use reusable components and clean folder structure.
* Do not create a simple demo or landing page. Build the actual working application UI.

==================================================
PROJECT PURPOSE
===============

AI Khet Saathi helps farmers maintain a digital record of farming activities and remember important dates.

The farmer can manage:

* Multiple farms
* Multiple crops
* Sowing dates
* Irrigation records
* Spray records
* Fertilizer records
* Pest/disease observations
* Other farming activities
* Expenses
* Reminders
* Activity history
* Crop summaries
* AI assistant

The UI must be extremely simple and mobile-friendly.

The design should feel friendly and trustworthy rather than like a complicated enterprise dashboard.
