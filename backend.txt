Build the complete backend for the **AI Khet Saathi** application.

IMPORTANT:

* Backend must be built separately from the React frontend.
* Use Django + Django REST Framework.
* The existing React frontend will consume these APIs later.
* Do NOT build React in this phase.
* Build a production-style REST API.
* Use PostgreSQL.
* Use environment variables for secrets.
* Include authentication, permissions, validation, database relationships, reminders, notifications and AI integration.
* The backend must be fully functional, not just model definitions.

==================================================
PROJECT PURPOSE
===============

AI Khet Saathi is a farmer-friendly farm diary and reminder platform.

Farmers can:

* Manage farms
* Manage crops
* Record farming activities
* Record spray/fertilizer/irrigation activities
* Track expenses
* Create reminders
* View activity history
* Ask AI questions about their own farm records
* Use natural language to create activity drafts
* Upload images
* View reports

AI should primarily operate on verified data stored in the user's database.

AI ASSISTANT
============

Build the AI assistant as a separate Django application.

Endpoint:

POST /api/ai/chat/

Request:

{
"message": "Maine soybean mein last spray kab kiya tha?"
}

Backend should:

1. Authenticate the farmer.
2. Understand the user's intent.
3. Identify relevant farm/crop/activity data.
4. Query the database.
5. Provide only relevant user-owned data to the AI.
6. Generate a simple answer.
7. Return the answer to React.
8. Store the conversation.

==================================================
AI SAFETY / DATA RULE
=====================

IMPORTANT:

AI must NOT invent farm history.

If data does not exist:

"The app does not have a recorded activity for this."

Do not make up dates.

The AI should clearly distinguish:

* Stored farm data
* AI-generated explanation
* General information

For questions involving pesticide dosage, disease treatment or agricultural chemical recommendations, do not invent medical/agricultural instructions.

Prefer:

"I don't have verified information for this recommendation. Please check the product label or consult a qualified agricultural professional."

The initial application is primarily a farm record and reminder assistant.

NATURAL LANGUAGE ACTIVITY CREATION
==================================

Create endpoint:

POST /api/ai/parse-activity/

Input:

{
"message": "Aaj subah soybean ko paani diya."
}

AI should return structured data:

{
"activity_type": "IRRIGATION",
"crop_name": "Soybean",
"activity_date": "2026-10-03",
"confidence": 0.95,
"notes": "Morning irrigation"
}

IMPORTANT:

Do NOT automatically save the activity.

Return it as a draft.

React will show:

"AI understood this activity."

Then user confirms.

After confirmation:

POST /api/activities/

creates the actual database record.
